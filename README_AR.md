# منصة التوثيق والمتابعة — النسخة المحدثة

هذه النسخة مخصصة للتشغيل على GitHub Pages فقط.

## التعديلات
- سجل الدخول يسجل نوع الجهاز ونظام التشغيل والمتصفح ومعرف الجهاز، مع مزامنة السجل ضمن بيانات GitHub عند توفر صلاحية الكتابة.
- إزالة بطاقة «المواضيع المنتهية» من شاشة المواضيع؛ الموضوع المنجز يظهر في الأرشيف.
- إضافة مسار متابعة لكل إجراء: داخلية أو خارجية، مع دعم نوع موضوع «داخلي + خارجي».
- Token لا يتم وضعه داخل المستودع أو `data.json`. يتم حفظه محلياً على الجهاز بعد إدخاله، ويظهر لاحقاً كـ «محفوظ على هذا الجهاز».

## ملاحظة مهمة عن Token
GitHub Pages لا يوفّر خادماً سرياً داخل الصفحة يمكنه حفظ Token للمستخدم ثم مشاركته بأمان بين الهاتف والكمبيوتر. لذلك لا تحفظ هذه النسخة الـToken الخام في المستودع. إذا استُخدمت المنصة من جهاز جديد، يجب إدخال الـToken على ذلك الجهاز مرة واحدة.
